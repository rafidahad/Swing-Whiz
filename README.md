# Swing Whiz 🕸️

**Swing Whiz** is a 2D physics-based arcade game where players navigate by swinging from anchor to anchor. Developed as a university project, the game relies on real-life physics simulations to create fluid, momentum-based movement and highly engaging gameplay.

## 🎮 Gameplay & Features

*   **Realistic Physics Simulation:** Features momentum, gravity, and pendulum-like swinging mechanics.
*   **Dynamic Anchors:** Players must time their releases and attachments to grapple from one anchor point to the next without falling.
*   **Custom 2D Engine Rendering:** Built entirely from scratch using the primitive drawing functions of the iGraphics library.
*   **Fun & Addictive Loop:** Easy to pick up, but difficult to master the perfect swing trajectory.

## 🛠️ Technology Stack

*   **Languages:** C, C++
*   **Graphics Library:** [iGraphics.h](https://github.com/iGraphics/iGraphics) (A custom wrapper over OpenGL/GLUT used widely for academic projects)
